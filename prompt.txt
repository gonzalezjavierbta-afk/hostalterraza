# CONTEXT PACKAGE: DESARROLLO DE SILO ATÓMICO c4 (v1.7.6-CINEMA)

Proyecto: Sistema QR Hostal Terraza
Versión Base: v1.6.0-STABLE (Contrato v110)
Rol solicitado: Creative Director (Creative AI)
Objetivo: Desarrollar el archivo de estilos c4.css para la plantilla "Interactive Cine"

1. REGLAS DE GOBERNANZA (Innegociables)
- Nomenclatura Estricta: El template pertenece a la categoría Cine (c). Todo el CSS debe estar encapsulado bajo el selector de ámbito .tpl-c4 [cite: 660].
- Aislamiento de Variables: Prohibido modificar el :root global. Todos los tokens deben usar el prefijo --c4- [cite: 660].
- Protocolo de Cero Borrado: No elimines ningún ID lógico del HTML (#db-*, #mod-*, #meta-*). Los módulos no usados deben ocultarse con display: none !important [cite: 656].
- Estándar de Oro ($10,000): Implementar tipografía Geist 900 en tarjetas, micro-interacciones "Afterglow" y diseño Native Mobile [cite: 660, 664].

2. ESPECIFICACIONES DE DISEÑO
- Concepto Visual: Experiencia de alta fidelidad interactiva, similar a una plataforma de streaming premium (estilo Apple TV+).
- Paleta 60-30-10: Dominante (60%) Negro profundo #050505; Secundario (30%) Gris carbón con glassmorphism; Acento (10%) inyectado por --master-accent [cite: 663].

3. ESTRUCTURA TÉCNICA
- Diagramación: Organizar #main-content-flow mediante grid-template-areas en CSS [cite: 661].
- Módulos Prioritarios: #mod-trailer (miniatura HD + link externo), #mod-sinopsis, #mod-director (foto y bio), #mod-gallery y #mod-info-tecnica [cite: 659].

4. RESULTADO ESPERADO
- Un archivo c4.css balanceado que, al inyectarse, active los latidos de salud del Escudo GOLD en consola: INFO, LINK, TRACE y TIME [cite: 657, 658].
