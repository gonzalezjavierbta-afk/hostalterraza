Configuración de Supabase

Conecta la base de datos para que el sistema funcione en todos tus dispositivos en tiempo real.

Pasos para obtener tus credenciales
1
Crea una cuenta gratuita en Supabase
Ve a supabase.com → Sign Up → crea un nuevo proyecto. Dale cualquier nombre (ej. "hostal-terraza").
2
Crea las tablas con el script SQL
En tu proyecto Supabase: SQL Editor → New Query → pega el contenido del archivo supabase_setup.sql → Run.
3
Copia tu URL y API Key
En Supabase: Project Settings → API. Copia la Project URL y la anon / public key.
Project URL: https://xxxxxxxxxxxx.supabase.co
anon key: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
4
Habilita Realtime
En Supabase: Database → Replication → activa las tablas inscritos y logs.
5
Pega tus credenciales abajo y guarda
El sistema se conectará automáticamente y el indicador "BD" en el menú se pondrá verde.
